- UX/UI Case Study & Interaction Design
- รายวิชา 520351 Human-computer interaction and interface design. (HCI) มหาวิทยาลัยศิลปากร


📌 Project Overview
- FluxFocus เป็นโมบายล์แอปพลิเคชันตัวอย่างที่ออกแบบขึ้นเพื่อแก้ปัญหาการบริหารเวลาและการจัดการภาระงานของนักศึกษามหาวิทยาลัยและวัยทำงาน ที่มักประสบปัญหาการผัดวันประกันพรุ่ง ทำงานไม่ทันตามเดดไลน์ หรือเกิดภาวะเครียดเมื่อมีงานด่วนและงานยากถาโถมเข้ามาพร้อมกัน โดยมุ่งเน้นการช่วยจัดลำดับความสำคัญอัตโนมัติ และการแบ่งงานใหญ่ให้เป็นงานย่อยที่เริ่มต้นลงมือทำได้ทันที

👤 บทบาทและความรับผิดชอบของฉัน
- ในโปรเจกต์กลุ่มนี้ ฉันรับผิดชอบในบทบาท UX Researcher และ UI Designer (หน้า Timeline & Micro-tasks & Login) โดยมีขอบเขตหน้าที่ดังนี้
	- UX Research & Empathize ออกแบบชุดคำถามและสัมภาษณ์กลุ่มเป้าหมายเชิงลึก (In-depth Interview) เพื่อค้นหาพฤติกรรม ปัญหา (Pain Points) และความต้องการที่แท้จริง

	- Synthesize & Define สร้าง User Persona ("น้องน้ำเหนียง") และ User Journey Map เพื่อวิเคราะห์จุดตกต่ำของอารมณ์ผู้ใช้พร้อมกำหนดโจทย์ How Might We ในการแก้ปัญหา

	- Ideation ร่วมระดมความคิดและคัดเลือกฟีเจอร์หลักของระบบ
	- UI Design (Figma) ออกแบบสเก็ตช์ Wireframe และทำ High-Fidelity UI ของ หน้าไทม์ไลน์ การแบ่งย่อยงานและหน้าล็อกอิน (Timeline & Micro-tasks Breakdown & Login)
	- Usability Testing ดำเนินการทดสอบต้นแบบ (Interactive Prototype) กับผู้ใช้จริง พร้อมสรุปประเด็นด้าน Affordance และ User Flow เพื่อนำมาปรับปรุง


🔍 กระบวนการออกแบบ 
 1.Empathize & Defineจากการสัมภาษณ์นักศึกษา 8 คน พบข้อค้นพบสำคัญ (Key Insights)
	- นักศึกษามักเลือกทำงานง่ายก่อน และผลัดงานยากและงานกลุ่มไปไว้ช่วงใกล้เดดไลน์จนทำไม่ทัน
	- อาการ Notification Fatigue หากการแจ้งเตือนถี่เกินไป ผู้ใช้จะกดปิดทิ้งและลืมเดดไลน์จริง
	- ความยากในการเริ่มต้น งานโปรเจกต์ขนาดใหญ่ทำให้เกิดความท้อแท้และประเมินเวลาผิดพลาด

2.UI Design Highlight หน้าไทม์ไลน์และการแบ่งย่อยงาน (Timeline & Sub-tasks)
- หน้านี้ถูกออกแบบมาเพื่อแก้ปัญหา "งานใหญ่จนไม่รู้จะเริ่มตรงไหน" โดยมีหลักคิดในการออกแบบ (Design Decisions)
	- Horizontal Date Strip & Calendar View แถบเลือกวันแนวนอนด้านบน ช่วยให้ผู้ใช้สแกนดูงานของแต่ละวันได้อย่างรวดเร็ว และสามารถแตะเพื่อขยายเป็นปฏิทินรายเดือนได้
	- Color-Coded Priority ใช้แถบสี (แดง/ส้ม) สื่อสารระดับความเร่งด่วนของงาน ช่วยลดภาระการประมวลผลทางสายตา 
	- Micro-task Auto-Breakdown ฟังก์ชันย่อยงานใหญ่เป็นเปอร์เซ็นต์ย่อย (เช่น 25%, 50%) ช่วยให้ผู้ใช้เห็นความคืบหน้าและลดแรงต้านในการเริ่มต้นทำงานชิ้นใหญ่
